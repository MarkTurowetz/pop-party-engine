# Third-party notices

Pop Party Engine source is licensed under the MIT License. Canonical starter
art and content are separately released under CC0-1.0 and inventoried in
`packages/create-game/starter/ASSET-NOTICES.json`.

The complete dependency inventory is generated from the exact npm lockfile in
`THIRD_PARTY-LICENSES.json`. It records package name, version, license, and
resolved artifact for every locked third-party package. CI regenerates this
inventory in memory and fails if it differs from the committed file, if a
package omits its license, or if an unreviewed license identifier appears.

The reviewed license families currently present are:

- 0BSD
- Apache-2.0
- BSD-2-Clause
- BSD-3-Clause
- BlueOak-1.0.0
- CC-BY-4.0
- ISC
- MIT
- MPL-2.0

Copyright and license texts for installed packages remain available in their
published npm artifacts. Distribution and source-release tooling must retain
the package license files and this inventory.
